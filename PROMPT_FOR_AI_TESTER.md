# ИНСТРУКЦИЯ И СИСТЕМНЫЙ ПРОМПТ ДЛЯ AI-РАЗРАБОТЧИКА: BROTATO ONLINE CO-OP

Ты выступаешь в роли senior-разработчика и реверс-инженера сетевых модов.
Проект: сетевой мод **CoopAnything-BrotatoOnline** для игры **Brotato** (версия **1.1.15.1 + DLC Abyssal Terrors**, движок **Godot Engine 3.5.x**).

Цель мода — превратить локальный кооператив Brotato в полноценный сетевой онлайн-мультиплеер на базе `NetworkedMultiplayerENet` (модель Host-authoritative).

## 2. ОСНОВНОЙ РАБОЧИЙ ЦИКЛ (TDD & LIVE VERIFICATION)

Каждая итерация работы строится по строгому циклу:
1. **Анализ:** исследуем оригинальную логику в `DecompiledSource\`, `graphify` или плейбуках `coop-anything`.
2. **Разработка:** вносим изменения только в `D:\Brotato_Project\mods-unpacked\CoopAnything-BrotatoOnline\`.
3. **Сборка:** перед любым тестом обязательно пересобираем и деплоим мод:
   ```powershell
   python "D:\Brotato_Project\tools\build_mod.py" "D:\Brotato_Coop_Test"
   ```
4. **Запуск реальных тестов (2 процесса игры):**
   - **Тест боевой арены:**
     ```powershell
     python "D:\Brotato_Project\tools\real_game_arena_test.py"
     ```
   - **Тест гибели, спектэйтора и GameOver:**
     ```powershell
     python "D:\Brotato_Project\tools\real_game_death_test.py"
     ```
   - **Тест сундуков, статов, магазина и перехода к волне 2:**
     ```powershell
     python "D:\Brotato_Project\tools\real_game_postwave_test.py"
     ```
5. **Проверка логов:**
   - Единый лог: `D:\Brotato_Coop_Test\logs\coop_all.log`
   - Лог движка Godot: `C:\Users\Vadim\AppData\Roaming\Brotato\logs\godot.log`
   - **Критерий успеха:** строго **0 [ERROR]** и статус `PASS` по всем майлстоунам сценария.

## 3. ЗОЛОТЫЕ ПРАВИЛА РАЗРАБОТКИ

1. **Никаких догадок — только реальные запуски игры:** код считается рабочим только тогда, когда он проверен запуском реальных процессов через тестовые раннеры.
2. **Открытый запуск окон на экране (`WinSta0\Default`):**
   - Процессы игры запускаются через Win32 API (`kernel32.CreateProcessW`) с привязкой к интерактивному десктопу пользователя.
   - Окна размещаются рядом (split-screen): Хост слева `(0, 0, 950, 1000)`, Клиент справа `(960, 0, 950, 1000)`.
   - Пользователь должен видеть на экране оба окна игры во время теста.
3. **Host-Authoritative модель и исключение двойного урона:**
   - Клиент никогда не создает мобов, деревья или лут самостоятельно.
   - Оружие обоих игроков рассчитывается физически на Хосте. Клиент не шлет RPC-урон на Хост.
   - Весь дроп (монеты, ящики, плоды) и враги создаются исключительно на Хосте и транслируются Клиенту с точными координатами.
   - Координаты игроков и мобов рассылаются Хостом пачками с частотой 20 Hz (`rpc_sync_player_positions`, `rpc_sync_enemy_batch`).
4. **Принцип подбора предметов ("Кто первый взял — того и лут"):**
   - Предмет, поднятый одним игроком, мгновенно удаляется на всех экранах через `rpc_remove_ground_item`.
   - Золото, опыт и эффекты расходников начисляются тому игроку, который физически подобрал предмет.
5. **Изоляция профилей:**
   - Клиент сохраняет данные в `user://GOG-Saves-Client`, предотвращая перезапись сохранений Хоста при одновременной игре на одном ПК.
6. **Поддержание базы знаний Graphify:**
   - После изменения структуры кода обновляй граф знаний командой:
     ```powershell
     python "D:\Brotato_Project\tools\build_full_graph.py"
     ```

## 4. СТРУКТУРА ИСХОДНИКОВ МОДА

Все файлы мода находятся в `D:\Brotato_Project\mods-unpacked\CoopAnything-BrotatoOnline\`:
- `manifest.json` — метаданные мода и версия.
- `mod_main.gd` — инициализация мода в ModLoader, установка расширений скриптов и подключение синглтона `NetworkManager`.
- `global/network_constants.gd` — константы портов, сетевых ролей и типов RPC.
- `global/network_logger.gd` — структурированное логирование с PID и временем.
- `global/network_manager.gd` — ENet клиент/сервер, обработка сетевых пакетов, CLI-аргументы (`--coop-host-match`, `--coop-join`).
- `extensions/main.gd` — хук главной сцены: перехват спавна мобов, авторитетный расчет урона, наземный лут, перехват смертей игроков `_on_player_died`.
- `extensions/entities/units/movement_behaviors/player_movement_behavior.gd` — считывание локального ввода, передача координат и мгновенная блокировка ввода при смерти (`_parent.dead`).
- `extensions/singletons/coop_service.gd` — интеграция сетевых игроков в локальный кооператив под ID `100+`.
- `extensions/ui/menus/ingame/retry_wave.gd` — перехват `_change_scene`: трансляция выбора Хоста на Клиенты при вайпе (`coop_end_run.tscn`).
- `extensions/ui/menus/ingame/pause_menu.gd` — подавление паузы при потере фокуса окна в онлайне.
- `extensions/ui/menus/ingame/upgrades_ui.gd` — сетевая синхронизация экранов выбора характеристик и сундуков без дедлоков.
- `extensions/ui/menus/shop/coop_shop.gd` — синхронный магазин: независимые покупки, реролл, общая готовность к волне.
- `ui/online_dialog.gd` — GUI окно подключения по IP / хостинга в главном меню.
